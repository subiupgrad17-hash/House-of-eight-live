# House of Eight

Portfolio website for House of Eight, an independent creative freelancer working across content, video, motion, design and digital.

## Editing
- **Projects** (Selected work): edit `projects.js`. See `HOW-TO-ADD-WORK.txt`.
- **Images and videos**: put them in `assets/work/`.
- **Services, About, contact email**: edit `index.html`.

## Hosting
Static site, no build step. To publish on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
